# Time Twist (Famicom Disk System): Manual English Translation

## About
This repository manual resources for an English translation of Time Twist for the Famicom Disk System. Much thanks to Dustin Hubbard from Gaming Alexandria for providing the scans of the manual. Check out the original scans here:
[https://www.gamingalexandria.com/wp/2019/02/time-twist-rekishi-no-katasumi-de-zenpen](https://www.gamingalexandria.com/wp/2019/02/time-twist-rekishi-no-katasumi-de-zenpen)

The source code for the translation is located at [time-twist-fds-en](https://github.com/romh-acking/time-twist-fds-en).

## Fonts
The logo (in-game and in the manual) uses "ITC Eras Ultra Medium"

Everything else uses "A-OTF Shin Go Pro". This is a standard Japanese font you commonly see in video game font (or at least ones extremely close to it).
